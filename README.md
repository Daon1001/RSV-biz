# 🏆 메인비즈·이노비즈 AI 마스터 컨설턴트 v2.2

컨설턴트 내부용 메인비즈·이노비즈 인증 통합 관리 시스템

## ✨ v2.2 업데이트 (IT/소프트웨어업 추가)

메인비즈와 이노비즈 모두에 **IT/소프트웨어업** 업종이 추가되었습니다.

### IT업종 특화 평가 포인트

**메인비즈 IT업종 (성과관리 분야)**
- 매출 성장률 기준 상향 (IT업 고성장 특성 반영): 15~30% 이상도 일반 평가
- **매출액 대비 R&D 투자 비율** (1~7% 이상 평가)
- **자체 보유 SW·솔루션 현황** (외주개발 vs 자체 솔루션)
- **ISMS-P, CSAP, GS인증, SW품질인증** 등 IT/SW 특화 인증

**이노비즈 IT업종**
- **자체 솔루션·SaaS 매출 비중** (SI/외주 매출 대비)
- **PMF 달성 여부**, MRR/ARR 추이 (SaaS의 경우)
- **DevOps·CI/CD·IaC** 등 개발·운영 인프라 수준
- **PRD/로드맵, 스프린트 운영** 등 애자일 조직 평가
- **개발·연구인력 비율** (전체 인력의 50% 이상이면 가점)

## 🎯 전체 기능 요약

### 1. 4개 업종 맞춤 평가 (🏭 / 💼 / 🏗️ / 💻)
- 메인비즈 16개 항목, 이노비즈 16개 항목 (시스템) + 11개 항목 (기술등급)
- 업종별 성과·사업화 지표 완전 차별화

### 2. 증빙자료 체크리스트 자동 안내
각 항목마다 현장평가 시 필요한 증빙자료를 자동 안내

### 3. 점수 향상 우선순위 자동 도출
가장 큰 점수 차이가 나는 항목 TOP 5 자동 표시

### 4. AI 컨설팅 리포트 (Claude Sonnet 4.5)
업종 특성을 반영한 맞춤 분석 + 우선 개선 과제

### 5. 고객사 관리 (CRM 라이트)
회사 정보 등록 + 메인비즈/이노비즈 진단 이력 동시 보관

### 6. 신청 워크플로우 트래커
메인비즈/이노비즈 인증별 10단계 체크리스트

### 7. 통합 대시보드
메인비즈 + 이노비즈 통계 동시 표시
