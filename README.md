## 사용 흐름

```
사이드바에서 인증 유형 선택 (메인비즈 / 이노비즈)
① 고객사      회사명 · 사업자번호 · 업종 · 문서번호 접두어 등록
② 진단        부문별 탭에서 응답 → 실시간 총점
③ 결과·리포트  총점 · 구간별 달성률 · 보완 우선순위 → 결과보고서 HTML 발행
④ 증빙양식집   진단 결과 기반 자동 추천 → 작성용 HTML 발행
⑤ 관리자      사용량 통계 · 사용자 관리 · 승인 대기 · 상세 로그
```

고객사 하나에 메인비즈 · 이노비즈 응답이 각각 별도로 저장되므로 두 인증을 병행 진단할 수 있습니다.

### 산출물 1 — 진단 결과 보고서 (A4 가로)

메인비즈 10쪽 / 이노비즈 12쪽.
표지 · 결과 요약(게이지 + 부문별 바 + KPI) · 구간별 결과와 보완 우선순위 ·
항목별 진단 결과 · 준비해야 할 증빙서류 · AI 종합 소견(선택) · 판정 기준과 결격 요건 · 면책.

### 산출물 2 — 증빙양식집 작성용 (A4 세로)

- 화면에서 바로 입력, Tab 키로 다음 칸 이동, 붙여넣기 시 서식 제거
- 입력 내용 브라우저 자동 보관 + JSON 저장 · 불러오기
- 전체 인쇄 / ★게시용만 인쇄 / 문서별 개별 인쇄
- 회사명 · 문서번호 접두어가 전 문서에 자동 치환
